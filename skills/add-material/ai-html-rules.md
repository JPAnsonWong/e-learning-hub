# 製作 E_learning Hub 教材 HTML 的規則（給負責「創建 HTML」的 AI）

你要製作一份**單頁 HTML 教材**，之後會被放進學習網站，由網站的 iframe 顯示。網站會記錄孩子的學習時間、每題對錯和未做，**但前提是你的 HTML 在適當時機回報**。請嚴格按以下規則製作。

## 一、基本要求
1. **單一 HTML 檔**：CSS、JS 全部寫在同一個檔內；圖片用 `data:` URI。不要引用外部網路資源（CDN、外部字體、外部圖片），也不要用 `localStorage` 自己存進度（網站會統一記錄）。
2. **不得出現個人資料**：不要寫孩子的真實姓名、暱稱、學校名稱、住址。需要稱呼時用「女兒」或「兒子」。網站是公開的，這點非常重要。班別（如「3D」）可以寫。
3. 繁體中文，字體用系統字體：`"PingFang TC","Microsoft JhengHei",sans-serif`。
4. **適應各種螢幕**：手機、平板、電腦，以及 65 寸 4K 觸控大屏。用 `rem`、`vmin`、`clamp()` 等相對單位；按鈕和可點擊區域不小於 3rem；不要依賴滑鼠懸停；不要依賴鍵盤快捷鍵（觸控屏沒有鍵盤，每個功能都要有可點的按鈕）。
5. 頁面會放在 iframe 內，上方有一條約 3.6rem 的網站工具列。頁面高度請用 `100%`（不要用 `100vh` 加額外邊距），內容超出時頁面內捲動。
6. 設定有意義的 `<title>`（不含個人資料）。

## 二、作答回報（有任何要孩子作答的題目就必須加）
把下面兩個函式**原樣**放在 `<script>` 最前面：

```js
// ---- E_learning Hub 回報（只在被網站 iframe 載入時有效，單獨打開頁面時無任何作用）----
function elhReport(m){
  try{
    if(location.search.indexOf("elhdebug")>=0)console.log("ELH",JSON.stringify(m));
    if(window.parent!==window)window.parent.postMessage(Object.assign({elh:1},m),location.origin);
  }catch(e){}
}
function elhText(h){return String(h==null?"":h).replace(/<[^>]*>/g,"").replace(/\s+/g," ").trim().slice(0,200);}
```

### 1) 載入時回報總題數（一次）
```js
elhReport({type:"init", total: 題目總數});
```
`total` 只算**需要孩子作答的題目**數量，必須準確：網站用「總題數 − 已答題數」計算「未做」。

### 2) 每題「揭曉答案／批改」那一刻回報（每題一次）
```js
elhReport({
  type: "answer",
  q: 題號,            // 同一份教材內唯一（數字或字串）
  choice: 孩子的作答,  // 孩子有作答：選項序號、或輸入的文字（任何非 null 的值）；沒作答就看答案：null
  correct: true/false, // 是否答對（沒作答時填 false）
  text: elhText(題目文字),
  picked: 孩子的作答文字或 null,   // 例如所選選項的文字、或填空輸入的內容
  answer: elhText(正確答案文字)
});
```

### 各題型怎麼回報
| 題型 | `choice` | `picked` | `correct` |
|---|---|---|---|
| 選擇題 | 所選選項序號（0 起） | 所選選項文字 | 所選是否等於正確選項 |
| 填充題（多個空格） | 孩子填的內容（如 `"7|65"`） | 同上，用 ` / ` 隔開各空格 | **所有空格都對**才是 true |
| 配對／排序題 | 孩子提交的結果（字串） | 孩子提交的結果文字 | 完全正確才是 true |
| 沒作答就按「顯示答案」 | `null` | `null` | `false` |

### 回報時機的規則
- **只在答案被揭曉或提交批改那一刻回報**，不要在孩子還在選擇時回報。
- 孩子可以改答案再提交時，**每次提交都回報一次**，網站以同一題最後一次為準。
- 若頁面有「先選、再按顯示答案」的流程（像一般投影練習），在「顯示答案」按鈕的處理函式裡回報。
- 回報內容不得包含個人資料。

## 三、沒有作答的教材
純閱讀頁、知識卡片、影片等**沒有題目**的頁面，不需要任何回報，網站仍會記錄開始時間、停留時間和「完成」。

## 四、交付前自我檢查
- [ ] 單一 HTML 檔、無外部資源、無 `localStorage`
- [ ] 全檔搜尋過，沒有孩子姓名、暱稱、學校
- [ ] 所有功能都有可點的按鈕，不靠鍵盤
- [ ] 在手機寬度和大屏寬度下版面都正常
- [ ] 有題目的頁面：已放入 `elhReport` / `elhText`，`init` 的 `total` 等於題目數
- [ ] 每題揭曉答案時都有回報；用瀏覽器開 `你的檔案.html?elhdebug`，開發者工具 Console 作答一輪，確認每題都印出一行 `ELH {...}`，且 `correct`、`choice` 符合預期
- [ ] 沒作答直接看答案的情況：`choice` 為 `null`

完成後把 HTML 檔交給負責上傳的人，並說明：科目、適用階段、教材類型、預計學習分鐘數、題目數。
